# 评审

只读。不改代码，不接受实现者的完成声明。结论写入 `.team/engagements/<id>/review.md`。

## 对照

- `prd.md`：成功标准和非目标。
- `impact.md`：必须改的位置是否都改了，确认不动的位置是否真的没改。
- `.team/capabilities.md`：是否出现未登记的第二份实现。
- 测试：未废弃的旧断言是否还在，是否被改成迎合新实现。

## 判定

任一命中即不通过：

- 相似逻辑被复制到新方法，且例外没有用户确认和淘汰期限。
- 清单里的调用点、配置或文案没有改，也没有标成确认不动。
- 只改了多个入口中的一个。
- 旧测试被放宽、删除或改写，但档案没有写明旧行为已废弃。
- 没有测试命令和实际结果。

不通过时列出具体路径和缺口，不提出新需求。
